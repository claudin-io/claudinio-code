# Teste do ContentViewerModal

Este arquivo serve para testar o visualizador de conteúdo de texto.

## Como testar

1. No chat, clique em um link de arquivo .tsx ou .rs
2. O ContentViewerModal deve abrir com o Monaco Editor
3. Verifique:
   - Syntax highlighting correto
   - Line numbers visíveis
   - Word wrap funcionando
   - Scroll suave
   - Fechar com ESC
